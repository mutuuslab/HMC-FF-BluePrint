Post-SOP special scenarios
SW recall prevention — 장애 탐지 → Kill-switch L1 → blast radius 차단 → RCA → 패치 SOTA → re-enable
A/B experiment — VIN cohort split → Shadow/Treatment → exposure collect → stat test → winner deploy
Regional compliance — 규제 변경 → region gate flag update → COTA push → 즉시 적용 (binary 변경 없이)
핵심: Post-SOP이 FF의 진짜 가치가 실현되는 단계. Deploy(OTA 패키지 배포) ≠ Release(기능 활성화) 분리가 여기서 동작. COTA로 flag config만 변경하여 binary 없이 기능 제어. Kill-switch는 CrowdStrike급 사태 방지의 마지막 방어선.
